# frontend-design

Anthropic's official frontend design skill to eliminate "AI slop" UI components.

## Aesthetic Direction Rules

Before generating any HTML, CSS, or React components:

1. **Choose a Specific Theme / Vibe**: Define a distinct visual theme (e.g., "editorial minimalist", "retro-futuristic", "brutally functional", "warm organic").
2. **Typography**: Avoid generic system defaults (`Inter`, `Roboto`). Choose curated Google Fonts paired with clear typographic scale (display, heading, body, mono).
3. **Color Palette**: Use tailored HSL color tokens with explicit contrast ratios (WCAG AA). Avoid cliché hero gradients (purple-to-pink gradients on dark backgrounds).
4. **Spacing & Grid**: Enforce strict 8pt grid spacing (`8px`, `16px`, `24px`, `32px`, `48px`).

## Output Format

Return production-ready, fluidly responsive components with zero placeholders.
