# Directive-docs system-prompt augmentation experiment

> Phase: 1. Type: spike. Ideation approach: failure-mode.
> Filed: 2026-08-06. Sources verified: 2026-08-06.

## Background

The cheapest possible mitigation for stale-training-data output is a directive in the system prompt: "do not rely on training-data knowledge of library versions; consult the registry at edit time." Hakim Ziad's report claims this 5-line directive cut deprecated output from 100% to 0% in their setup. Before building the heavier infrastructure (#36, #37), heretek should validate that a prompt-level intervention actually works in our context — and document the failure modes if it doesn't.

## Research Summary

- Hakim Ziad: a 5-line directive cut deprecated output 100→0% in their setup ([hakim-ziad](https://medium.com/@hakim.ziad/how-to-stop-coding-agents-from-using-stale-versions-473dcea7359d), verified 2026-08-06).
- Lunidev 2026 developer guide: training-data currency is a known developer-experience failure mode and the guide recommends prompt-level guardrails as a first line ([lunidev](https://lunidev.com/dev/blog/ai-training-data-currency-developer-guide-2026), verified 2026-08-06).
- Cross-cutting observation #3 from the research report: "forcing directive language helps" — the directive is *compatible* with this spec's #39 spike ([research report](https://docs.bswen.com/blog/2026-03-17-prevent-ai-hallucinations-outdated-docs/), verified 2026-08-06).

## Ideation Notes

*failure-mode-driven.* Failure mode: "model emits outdated API because prompt never told it not to." Intervention: a 5-line directive in the system prompt reminding the model to consult current sources. This spike validates the intervention in isolation, before layering on top of the freshness index (#36) and intercept hook (#37). Novel in the heretek context because we measure the directive's effect with our own model classes (Qwen3.6 27B, deepseek-class) — not a single-model demo.

## Scope

- Construct two system-prompt variants: control (no directive) and treatment (5-line directive).
- Run N=100 coding tasks per variant per model class (Qwen3.6 27B, deepseek-class).
- Measure: deprecated-API rate, stale-pin rate, task-completion rate, prompt-token delta.
- Record in `docs/superpowers/research/2026-08-06-directive-docs-experiment.md`.
- Decision deliverable: ship the directive in `heretek.toml` defaults, or "needs heavier intervention" → keep #36/#37/#45 path.

## Out of scope

- Modifying heretek's default system prompt (decision deliverable feeds a follow-up issue if positive).
- Testing all model classes — pick 2 representative ones.
- Combining directive + freshness index in the same experiment (orthogonal; spike tests directive alone).

## Hypothesis + method

**Hypothesis:** Adding a 5-line "do not rely on training-data knowledge of library versions; consult current sources at edit time" directive to the system prompt reduces deprecated-API usage in emitted code by ≥50% relative to control, with no measurable regression in task-completion rate.

**Method:**
1. Construct paired task set: 100 coding tasks, half Python, half JS, half Rust.
2. Run each task under (control, treatment) × (Qwen3.6 27B, deepseek-class).
3. Code-review output for: (a) any deprecated stdlib/library API, (b) any pin older than the freshness cache's `latest_version`, (c) task correctness.
4. Compute per-variant deprecated-API rate; check treatment rate is ≤50% of control rate.
5. Compute task-completion delta; flag as regression if >5% absolute drop.

**Success criteria:**
- Treatment deprecated-API rate ≤ 50% of control rate (Hakim Ziad benchmark).
- Task-completion rate delta within ±5%.
- Wall-clock overhead <2% (the directive is small).

**Decision deliverable:** ADR-style note at `docs/superpowers/adrs/00XX-directive-docs-decision.md` recommending either (a) ship directive as default, or (b) directive alone insufficient, escalate to #36/#37/#45 path.
