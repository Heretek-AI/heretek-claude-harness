## Background

This issue is one of four long-term measurement instruments for the spec's ideation methodology (per §5 of `2026-08-06-freshness-enforced-coding-roadmap-design.md`). Failure-mode-driven ideation is the most common type in the current roadmap (3 of 14 ship+spike items use it), making this test especially informative.

## Ideation Notes

*definitional — this test IS the failure-mode-driven ideation approach.* Failure-mode-driven ideation is the methodology of starting from observed failure modes (e.g., "Qwen3.6 27B emits outdated deps") and designing targeted interventions. This test issue codifies the methodology itself so its effectiveness can be measured over time. The current roadmap uses it more than any other approach, making this the most-instrumented of the four tests.

## Scope

- Define "effective failure-mode-driven ideation" via measurable proxies (below).
- Identify every roadmap item that uses this approach: #37, #39, #45 (3 items, per spec §3).
- Track per-item: shipped-on-time, success-criteria met, follow-up issues spawned, downstream adoption.
- Roll up at M12 and M24 with: per-item scorecard + cross-item correlation analysis + methodology-effectiveness verdict.

## Out of scope

- Measuring other ideation approaches (#50, #51, #53 cover them).
- Specifying the M24 roll-up report format.
- Cross-correlating failure-mode-driven items with external-data items (separate analysis if valuable).

## Measurement framework

**Definition of "effective ideation" for this approach:**
A failure-mode-driven ideation-produced roadmap item is *effective* iff (a) it ships on time, (b) its success criteria are met without major rework, (c) it spawns ≤1 follow-up issue per shipped item, and (d) it sees ≥1 downstream consumer within 6 months of ship.

**Measurement protocol:**
1. For each roadmap item using this approach (#37, #39, #45):
   - Ship date vs scheduled date (binary: on-time / late)
   - Success-criteria pass/fail per item's DoD
   - Follow-up issues count at M+6 and M+12
   - Downstream adoption count
2. Per-item scorecard at M+6, M+12, M+18, M+24.
3. Cross-item analysis at M12 and M24: which failure-mode-driven ideation sub-patterns correlate with on-time ship + success-criteria pass?
4. Methodology verdict at M24: continue, refine, or replace.

**Success thresholds:**
- ≥2 of 3 items ship on time (66%).
- ≥2 of 3 items meet success criteria without major rework.
- Average follow-up issue count per shipped item ≤1.5.
- ≥2 of 3 items see downstream adoption within 6 months.

**Data collection:**
- Issue tracker for ship dates and follow-up counts.
- Catalog telemetry (when available) for adoption.
- Per-item retrospective notes captured at ship time.
- Mid-cycle check-in at M6 and M12.

**Decision deliverable:** M24 methodology-effectiveness report (`docs/superpowers/research/2026-08-06-failure-mode-ideation-report.md`) with per-item scorecard, cross-item analysis, and verdict.
