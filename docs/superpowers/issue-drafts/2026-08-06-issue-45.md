# Lookup-gate hook (`scripts/lookup_gate.py`)

> Phase: 3. Type: ship. Ideation approach: failure-mode.
> Filed: 2026-08-06. Sources verified: 2026-08-06.

## Background

The freshness index (#36) and stale-dep intercept (#37) catch *dependency* staleness. They don't catch the broader failure mode: models emitting any code based on training-time memory when current docs exist. The lookup-gate hook is the enforcement generalization — if a model emits code calling a third-party API, it must have looked up the current API signature first. Lives as a D15 hooks-plugin feature.

## Research Summary

- bswen: Context7 MCP prevents hallucinated-deprecated-method output by serving real-time docs ([bswen](https://docs.bswen.com/blog/2026-03-17-prevent-ai-hallucinations-outdated-docs/), verified 2026-08-06).
- Cross-cutting observation #2 from the research report: external-data triangulation works — successful freshness mitigations all involve fetching external state at edit time ([research report](docs/superpowers/research/2026-08-06-freshness-enforced-coding-research.md), verified 2026-08-06).
- Hakim Ziad describes an anecdotal MinIO incident involving a directive to address stale versions; it motivates pairing directives with an observable enforcement gate, but does not establish a controlled efficacy benchmark ([hakim-ziad](https://medium.com/@hakim.ziad/how-to-stop-coding-agents-from-using-stale-versions-473dcea7359d), verified 2026-08-06).

## Ideation Notes

*failure-mode-driven.* Failure mode: "model emits `requests.get(url).json()` based on training memory, but the actual current signature has changed (or never existed as remembered)." The intervention generalizes the stale-dep pattern (#37) to all third-party API calls: every emitted API call must be backed by a recent Context7 (or equivalent) lookup, recorded in the edit log. Novel in heretek because it converts a soft directive (#39's prompt-level ask) into a hard enforcement gate that demands evidence per edit.

## Scope

- Hooks-plugin feature `lookup_gate` invoked on `PostToolUse:Edit`.
- Detects third-party API calls in the diff (via AST for Python/JS, regex fallback for others).
- Requires a recent, machine-recorded lookup (within the active session) keyed to each called API.
- Observable evidence source: a hook-maintained `.heretek/last_lookup.json` record written by the Context7/catalog lookup adapter from the tool-call event, containing `session_id`, normalized API/library keys, `tool_name`, and `timestamp`; agent self-report or an arbitrary edit is not accepted.
- Accepted lookup sources are Context7 MCP and the internal catalog (`catalog/freshness/<lib>.yaml`); each accepted tool call must update the evidence record. Default: warn. Block mode opt-in via `heretek.toml`.

## Out of scope

- Auto-fetching missing lookups (the model must do it explicitly; the gate enforces intent).
- Stdlib calls (not external — always allowed).
- Custom lookup sources beyond Context7 + heretek catalog (defer to Phase 4).

## Suggested catalog.yaml entry shape

```yaml
# catalog/plugins/hooks/commands.yaml (additive entry)
- name: lookup_gate
  script: scripts/lookup_gate.py
  triggers:
    - PostToolUse:Edit
  default_severity: warn
  config:
    lookup_sources:
      - context7
      - catalog/freshness/
    require_recent_within_session: true
    evidence_file: .heretek/last_lookup.json
    require_recorded_tool_event: true
    exclude_stdlib: true
```
