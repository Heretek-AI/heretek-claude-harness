# heretek marketplace v1.0.0 — Release Notes

> Date: 2026-08-05. First public release of the `heretek` Claude Code marketplace.

## What is this?

`heretek` is an opinionated Claude Code plugin marketplace bundling 11 first-party plugins — task plugins (rust, python, js-ts, web-frontend) plus cross-cutting packs (hooks, security, skills-pack, mcp-pack, lsp-pack, agents, output-styles).

## Install

```bash
/plugin marketplace add Heretek-AI/heretek-claude-harness heretek
/plugin install rust@heretek
# or install all 11:
/plugin install rust@heretek python@heretek js-ts@heretek web-frontend@heretek \
  hooks@heretek security@heretek skills-pack@heretek mcp-pack@heretek \
  lsp-pack@heretek agents@heretek output-styles@heretek
```

## What's in v1.0.0

- 11 first-party plugins, all with SHA-pinned content (D11) and per-item vetting records (D7).
- 67+ tests passing; CI green on `main`.
- Daily security-scan cron detecting upstream releases; SHA-bump PRs drafted automatically.
- Quarterly refresh script (`scripts/refresh_pins.py`) for maintainers.
- Security intake via GitHub Security Advisories on this repository (see `SECURITY.md`). Wiring of `security@heretek.ai` as the primary mailbox is tracked separately as [#12](https://github.com/Heretek-AI/heretek-claude-harness/issues/12) and is deferred to v1.0.1.

## Vetting

Every item in the marketplace passes the D7 bar: stars ≥ 500, last commit ≤ 12 months, OSI-approved license, source audit for code-executing components, no critical CVEs in the last 24 months. See `docs/superpowers/specs/2026-08-03-heretek-marketplace-design.md` §8 for the written policy.
