# Create a Morphe Patch

End-to-end workflow for authoring a new patch in a Morphe Patcher Kotlin DSL bundle (`morphe-patches` or a fork of `morphe-patches-template`).

## When to use

Use this skill when the user wants to:

- Author a new patch from a description + a base APK.
- Add a fingerprint for a method that needs to be patched.
- Define a `Compatibility` block for a target app.
- Ship a `.mpe` extension alongside a patch.
- Run the Gradle build and verify the patch appears in `patches-list.json`.

**Do NOT use this skill for:**

- Modifying the Morphe Patcher engine itself.
- Building the Morphe Manager Android UI.
- Non-Morphe APK modification (e.g., standalone smali edits without a patch bundle).

## Inputs required

Before starting, gather:

1. **Base APK path** — the original Play-signed `base.apk` (or any signing variant the patch should accept).
2. **Target app package** — `packageName` (e.g., `com.grindrapp.android`).
3. **Target app version** — at least one `version` string in `targets`. Multiple versions are fine.
4. **Human description of behavior** — what should the patch do? A single sentence is enough.
5. **Optional: `.mpe` extension source** — only if the patch needs compiled Java/Kotlin code injected.

## Workflow

1. **Capture the signature.** Run `scripts/compute-signature.sh <base.apk>` to get the delegated signer SHA-256. Use it for `Compatibility.signatures`. See `references/compatibility-block.md`.
2. **Author the fingerprint.** Open `references/fingerprinting.md` and construct a `Fingerprint {}` that uniquely identifies the method to patch. Prefer robust attributes (return type, parameter types, instruction filters) over obfuscated names.
3. **Declare compatibility.** If the patch targets a specific app, create a `Compatibility` instance per `references/compatibility-block.md`. If universal, omit it.
4. **Write the patch class.** Use `assets/PatchTemplate.kt` as a starting point. Follow the conventions in `references/structure-and-conventions.md` (verb-led name, third-person description, modularity).
5. **Add a `.mpe` extension if needed.** See `references/patch-anatomy.md` ("Extensions"). Use `assets/extension-stub/` as the skeleton and `extendWith("…mpe")` from the patch.
6. **Build the bundle.** Run `./gradlew :patches:buildAndroid :patches:generatePatchesList`. The generated `patches-list.json` should contain your new patch.
7. **Validate.** Run `scripts/validate-patch.sh "<patch substring>"` to confirm the build succeeded and the patch is registered.

## Common pitfalls

A short list with one-line fixes. Full discussion in `references/common-pitfalls.md`.

- ❌ Editing `patches-list.json` or `patches-bundle.json` by hand → ❌ regenerated by Gradle. Edit the source.
- ❌ Using the upload cert SHA-256 instead of the delegated signer → use `apksigner verify --print-certs` on the Play-signed APK.
- ❌ Fingerprinting on obfuscated method names → ✅ use return type, parameter types, and instruction filters.
- ❌ `extendWith` with a dynamic list → use `extendWithAll` so the provider is evaluated at patch time.
- ❌ Reusing Morphe name/logos in a derivative bundle → ✅ GPLv3 §7 prohibits this; pick your own brand.
- ❌ Missing `compatibleWith` → the patch is universal; usually that's wrong. Be explicit.

## Minimal worked example

Disable ads in `app.xyz.mobile` version `2.0.0`. Compute the signature, then:

```kotlin
// patches/src/main/kotlin/app/morphe/patches/xyz/AdsDisabled.kt
package app.morphe.patches.xyz

import app.morphe.patcher.Fingerprint
import app.morphe.patcher.bytecodePatch
import app.morphe.patcher.patch.Compatibility
import app.morphe.patcher.patch.AppTarget
import app.morphe.patcher.patch.PatchException
import app.morphe.patcher.opcode
import app.morphe.patcher.string
import app.morphe.patcher.fieldAccess
import app.morphe.patcher.Opcode

private const val PACKAGE = "app.xyz.mobile"
private const val VERSION = "2.0.0"

// 1. Replace with: bash scripts/compute-signature.sh base.apk
private const val SIGNATURE = "REPLACE_WITH_DELEGATED_SIGNER_SHA256"

private val COMPATIBILITY = Compatibility(
    packageName = PACKAGE,
    name = "XYZ",
    apkFileType = ApkFileType.APK_REQUIRED,
    appIconColor = 0xFF3300,
    signatures = setOf(SIGNATURE),
    targets = listOf(AppTarget(version = VERSION)),
)

private object ShowAdsFingerprint : Fingerprint(
    definingClass = "Lapp/xyz/ads/AdsLoader;",
    returnType = "Z",
    parameters = listOf("Ljava/lang/String;", "I"),
    filters = listOf(
        fieldAccess(opcode = Opcode.IGET, definingClass = "this", type = "Ljava/util/Map;"),
        string("showBannerAds"),
    ),
)

@Suppress("unused")
val disableAdsPatch = bytecodePatch(
    name = "Disable ads",
    description = "Disables ads in the app.",
    default = true,
) {
    compatibleWith(COMPATIBILITY)
    execute {
        ShowAdsFingerprint.let { match ->
            match.method.addInstructions(
                0,
                """
                    const/4 v0, 0x0
                    return v0
                """,
            )
        }
    }
}
```

Then build:

```bash
bash scripts/validate-patch.sh "Disable ads"
```

If the script exits 0, the patch is registered. If it exits 1, read the Gradle output.
